# What to cover, by kind of work

Read this at the start of a task to pick what each step explains and which standards of the field to teach. These are widely held practices of each field; say "most practitioners…" when something is a convention rather than a rule.

## Code
- **Explain**: each function, class or component — what it does, why it exists, how it fits the rest.
- **Standards to teach**: names that say what a thing is; small functions with one job; validate input where it enters; handle the error path, not only the happy one; one small test or self-check for non-trivial logic.
- **Beginner mistakes to watch for**: off-by-one indexes, mutating a list while looping over it, comparing text without normalising it, swallowing errors silently.
- **Show**: the code under each step; for edits, the changed part. Always the run command.

## Documents, PDFs, slides
- **Explain**: the structure and why; the tool or library and why; the steps that produce the file.
- **Standards to teach**: one idea per section or slide; headings that tell the reader what they'll find; consistent styles instead of hand formatting; the audience decides length and tone.
- **Beginner mistakes**: walls of text, inconsistent fonts and spacing, missing page numbers or contents in long documents.
- **Show**: the outline first, then each section; say how to open the file.

## Spreadsheets, data
- **Explain**: each formula, transformation or chart — what it computes, why, how to read it.
- **Standards to teach**: raw data kept untouched, work done in separate columns or sheets; one row per record; units in headers; check totals against a known figure; charts chosen by the question (trend → line, comparison → bar, part of a whole → only a few slices).
- **Beginner mistakes**: hard-coded numbers inside formulas, mixed units, averaging averages, charts with distorted axes.
- **Show**: the formula as text, a worked example with real cells.

## Writing, reports
- **Explain**: the outline, the tone, the key choice in each section.
- **Standards to teach**: the conclusion or recommendation first for busy readers; one claim per paragraph with its evidence; plain words over jargon; sources for every fact that matters.
- **Beginner mistakes**: burying the main point, unsupported claims, the same idea repeated in every section.
- **Show**: the outline, then the text section by section.

## Any other field
Name it, and teach its own vocabulary, practices, beginner mistakes and standard of good work. Unsure of a field's standard → say so and check rather than invent one.
